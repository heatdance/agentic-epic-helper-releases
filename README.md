# Agentic epic helper

Cursor harness for **agent-assisted QA** on product epics: playbooks, JSON artefacts, and verification tools. This is **not** the product application source tree.

## Start here

| Who | Read first |
|-----|------------|
| Humans | [HOW-TO.md](HOW-TO.md) |
| Agents | [AGENTS.md](AGENTS.md), then [docs/harness-map.json](docs/harness-map.json) |

## What’s in the box

- **Pipelines** — prepare epic → coverage → gaps → link surfaces → draft tests → archive ([HOW-TO.md](HOW-TO.md))
- **Templates** — schemas under `epics/templates/`
- **Automation** — tools and docs under `automation/`
- **Doctrine** — [docs/harness-principles.md](docs/harness-principles.md)

## Distribution

The same README ships on every line. What else is present (full workspace, shared harness, or guide-only export) depends on which clone you have — use the HOW-TO and AGENTS that came with it.
